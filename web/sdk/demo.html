معادلات عربية SDK

استخدم محرر المعادلات نفسه داخل تطبيقاتك، مثل كشكول وراجع: لكتابة الأسئلة والحلول، وعرض المعادلات العربية والكيميائية بجودة عالية.

١) فتح المحرر والحصول على المعادلة

النتيجة تظهر هنا

<script src="https://wazni.ly/sdk/armath-sdk.js"></script>
ArabicMath.openEditor({ mode: 'math', tex: 'جا^2 س + جتا^2 س = 1' })
  .then(function (res) {
    // res.latex, res.svg, res.png (data URL), res.mathml, res.widthPt, res.heightPt
    document.getElementById('answer').innerHTML = res.svg;
  });

٢) عرض معادلة بدون فتح المحرر (سؤال في كشكول أو راجع)

أوجد قيمة إذا كان 

ArabicMath.render('نها_{س \\to 0} \\frac{جا س}{س}', { fontSize: 16, color: '#0a7c78' })
  .then(function (r) { el.innerHTML = r.svg; });   // أو r.png لصورة

٣) الرسوم البيانية والأشكال الهندسية والصيغ البنائية

الرسم يظهر هنا
ArabicMath.openGraph({ data: { fns: [{ expr: 'جا س' }], piTicks: true } }).then(function (res) { el.innerHTML = res.svg; /* res.data للتعديل لاحقاً */ });
ArabicMath.openGeometry({ tpl: 'right' });
ArabicMath.openStructure({ smiles: 'CC(=O)Oc1ccccc1C(=O)O', name: 'الأسبرين' });

٤) تطبيقات الجوال (Flutter / React Native)

حمّل الرابط https://wazni.ly/editor.html?host=sdk داخل WebView. عند الضغط على «إدراج» تصلك النتيجة JSON فيها latex وsvg وpng:

  • Flutter (webview_flutter): أضف JavaScriptChannel باسم ArMath.
  • React Native (react-native-webview): عبر onMessage.

ولفتح معادلة جاهزة للتعديل أضف في آخر الرابط: #d={"host":"sdk","mode":"math","tex":"..."} بعد ترميزه بـ encodeURIComponent.
